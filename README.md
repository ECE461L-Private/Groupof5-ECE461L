# HaaS System Team Repository

This repository is the shared team workspace for the ECE 461L HaaS PoC project.

## Scope of this initial setup

This initial commit only includes repository scaffolding:
- project documentation templates
- planning and tracking folders
- issue and pull request templates
- empty frontend/backend placeholder directories

No feature implementation is included in this setup.

## Reference

- Project handout PDF: `EE 461L Team Project (2) (1).pdf`

## Proposed repository layout

- `docs/requirements.md`: stakeholder needs and requirements extracted from the handout
- `docs/project-plan-template.md`: phase planning template for the team
- `docs/architecture/`: place high-level sketches and architecture diagrams
- `docs/user-stories/`: user stories and story tracking notes
- `docs/meeting-notes/`: standups and team meeting notes
- `.github/ISSUE_TEMPLATE/`: bug and user-story issue templates
- `.github/pull_request_template.md`: PR checklist
- `src/frontend/`: frontend app code (to be added by team)
- `src/backend/`: backend/API/db code (to be added by team)

## Team workflow expectations

- Track bugs and improvements in GitHub Issues.
- Track user stories on project boards.
- Keep PRs small and linked to issue IDs.
- Use one repository across all project phases.
