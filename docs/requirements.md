# Stakeholder Needs and Initial Requirements

This file captures initial requirements from the course handout screenshots/PDF.

## Stakeholder Needs (SN)

- SN0: Accepted quality and reliability metrics
- SN1: Create and maintain secure user accounts and projects
- SN2: View status of hardware resources
- SN3: Request available hardware resources
- SN4: Checkout and manage resources
- SN5: Check-in resources and get resource status
- SN6: Deliver PoC within schedule constraints with support for scalability

## Initial System Requirements (from handout)

- SR1: Deliver PoC within budget/schedule with periodic stakeholder updates (maps to SN6)
- SR2: Provide a front-end web app for user inputs and outputs (maps to all)
- SR3: Provide encryption mechanism for user-id/password (maps to SN1)
- SR4: Provide mechanism for creating/accessing projects (maps to SN1)
- SR5: Maintain database for login credentials, project data, and resource data (maps to SN2-SN5)

## MVP Features (initial)

- User sign-in and new-user creation
- Create new project and access existing project
- Persist user/project data in database
- API access to stored information
- Encrypt user credentials
- Resource display for capacity and availability
- Request checkout/check-in quantities
- Persist and retrieve hardware resource data

## General Team Requirements

- Single repository for all phases
- Use issue tracking for bugs/improvements
- Keep user stories on project board
- Define/refine user stories through Phase 1+
